# 🎮 Игра "Угадай слово" (main.py)

Это простая текстовая игра, в которой пользователь должен угадать слово по его значению. Слова и определения берутся с сайта [randomword.com](https://randomword.com), после чего переводятся на русский язык с помощью Google Translate.

## 🧠 Как работает игра

1. Получается случайное английское слово и его определение.
2. Оба переводятся на русский язык.
3. Игроку показывается **определение** на русском, и он должен угадать, какое **слово** имелось в виду.
4. После ответа выводится результат и предлагается сыграть снова.

## 🔧 Зависимости

- `requests` — для загрузки страницы
- `beautifulsoup4` — для парсинга HTML
- `googletrans` — для перевода текста
